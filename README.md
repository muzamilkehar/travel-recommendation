# Travel Explorer — Travel Recommendation Web Application

A responsive front-end travel recommendation website built with HTML, CSS and vanilla JavaScript.

## Features
- Home, About Us and Contact Us sections
- Responsive navigation menu
- Search and reset functionality
- Beach, temple and country recommendations (two images in each category)
- Contact form with front-end validation and demo confirmation
- Responsive desktop and mobile layouts

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.

No build tools or dependencies are required.

## Deploy using GitHub Pages
1. Create a public GitHub repository named `travel-recommendation`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the deployment and open the URL shown in the Pages section.

The expected URL format is:
`https://YOUR-USERNAME.github.io/travel-recommendation/`

## Important note about the contact form
This is a front-end demonstration. It validates the form and displays a confirmation message, but it does not send an email. A backend or email service is required for real email delivery.
